## 部署到 Vercel（3 分钟）

1. 注册/登录 https://vercel.com（用 GitHub 账号最快）。
2. 点 **Add New → Project → Import → "Continue with..."**，或者直接拖整个文件夹到 Vercel 的 dashboard。
   - 命令行也行：`npm i -g vercel && vercel`，按提示一路回车。
3. Vercel 会自动识别为静态站点，不需要任何配置。
4. 部署完成后会拿到一个 `xxx.vercel.app` 链接。可以在 Project Settings → Domains 里改成更好看的子域名（比如 `gengchengkang.vercel.app`）。

> 文件夹名含中文/空格：Vercel 部署本身没问题，但建议把根目录重命名为纯英文（例如 `tianyuan-talking-site`）再 push，避免极个别浏览器缓存路径问题。

## 放入证件照（必须，否则 Hero 和 About 会显示破图）

代码已经按 `assets/portrait.png` 引用照片。**抠图后保存为透明背景的 PNG** 才能让 Hero 区"剪影 → 鼠标揭露彩色照片"的效果生效。

### 三步搞定

1. 打开 https://www.remove.bg/ （免费，30 秒）。
2. 上传你的证件照原图（白底那张），网站会自动抠出人像，下载出来的 PNG 是透明背景。
3. 把下载到的文件**重命名为 `portrait.png`**，放到本项目的 `assets/` 目录下。

> 备选：用 Photoshop / Affinity / Pixelmator 自己抠也行，关键是输出 PNG 且背景透明。
> 如果实在懒得抠，可以直接保存原图（白底）为 `portrait.png`，但 Hero 区的剪影效果就会变成"白色矩形 → 揭露彩色矩形"，不好看。

### Hero 区的设计意图

- 默认状态：你的头像剪影（纯黑），呼应"光影"主题。
- 鼠标靠近：揭露彩色证件照，跟着鼠标位置移动，像被一束光照亮。
- 鼠标移开：缓慢回到剪影状态。

这本身就是对 talking 摄影核心理念的视觉演示——"灯放在哪里，决定这个人怎么被看见"。

## 自拍布光指南（你给自己拍一张）

这张照片本身就是一件作品 —— 招聘者打开第一眼看到的就是它。**用单灯**就够，越简单越能体现控制力。

### 设备建议（任一组合都可以）

- 一盏可调亮度的 LED（南光 P60c / Aputure MC / 甚至一个 RGB 补光板都行）
- 一块大面积的柔光罩 / 柔光布 / 或就用一张白床单蒙在灯前 1 米处
- 反光板（白卡纸、泡沫板都行）
- 三脚架或稳定平面 + 手机定时拍摄即可。需要 4:5 或 3:4 竖构图。

### 灯位（伦勃朗光 / 短光）

```
              [背景，离人 1.5m+ ]
                    
       (rim 可选)
                          
                       [你 · 面对镜头 45°]
       
       [主光]   ←  与你脸成 45° 横向、高 30° 俯角，柔光罩朝向你
       
       [反光板]  ←  在你脸的另一侧，距离 0.8m 左右，把暗部抬一点
       
                    [相机 / 手机]
```

要点：
- **主光在脸侧 45°、略高于眼睛**，光打过来在远端鼻子/脸颊上形成一个倒三角的亮区，这就是经典的伦勃朗光，最显结构。
- **光比控制在 3:1 左右**：暗面不要黑死，但也不要平。看不清差别就把反光板拉远一点。
- **背景压暗**：人离背景至少 1.5 米，灯光不要溅到背景上。背景越暗，人越被"拎出来"。
- **眼神光必须有**：相机视角下，你的瞳孔里应该看得到主光那一小块亮。如果没有，主光太低或太靠后，往前移一点。
- **色温 3200K** 如果想暖一些（Hero 区暖调氛围匹配），或 **4500K** 中性。
- **服装**：纯色、深色（黑、灰、深绿、酒红）。不要花纹，不要白色（会糊）。

### 拍摄

- 半身或胸像，构图给眼睛留在画面上 1/3 处。
- 表情：自然、嘴角微抬即可，**不要假笑**。
- 镜头视角：略高于眼睛或平视。绝对不要从下往上拍。
- 焦距：等效 50–85mm（手机用人像模式，2x 镜头）。

### 后期

- 整体压暗，只把脸的高光区域留住。
- 对比度拉一档，饱和度收一点（-5 到 -10）。
- 锐化轻一点，不要边缘炸开。
- 输出：**JPG，宽度 1200px，质量 80**，文件大小 < 200KB。如果超过，再压一次。

成品命名 `portrait.jpg`，放到 `assets/` 下即可。

## 后续怎么往里加作品

`index.html` 里搜索 `<!-- ============== PORTFOLIO ROADMAP ============== -->`，那一段是 4 张占位卡片。每张卡片以后可以替换成：

- 视频 embed（B 站 `<iframe>` 或本地 `<video>`）
- 一组对比图（同一被摄者、不同布光）
- 一篇分析文章的链接

保持 4 张/8 张的网格节奏即可。
